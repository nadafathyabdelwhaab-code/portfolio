# بورتفوليو ندى أيمن — صانعة محتوى

موقع ثابت (HTML + ملف بيانات واحد). مفيش بناء ولا تثبيت.

## تعديل المحتوى
كل الكلام والأرقام في ملف `data.js` فقط.
- أي قيمة فاضية ("") مش بتظهر في الموقع.
- لكل علامة: `metrics` (followers / views / likes / posts) و `role` و `start` و `ongoing` و `result`.
- استخدمي أرقام موثقة من Insights أو من إحصائيات الحساب فقط.
- العينات في `samples` هي نماذج كتابة وليست منشورات منشورة.

## التشغيل محليًا
افتحي `index.html` في المتصفح.
